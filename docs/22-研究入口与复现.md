# 研究入口与复现
更新：2026-10-16。

项目有两种使用方式。实验分析工作区根据已登记的 Hillstrom 问题查询数据库、计算结果并生成报告；研究工作区读取保存好的研究汇总，帮助读者理解最新证据和成本决策。后者把新研究接入展示与决策讨论，不代表自然语言入口已经能重训所有研究模型。

## 无外部服务的研究入口

安装后在任意工作目录运行：

```bash
python -m dsa.research_portal --list
python -m dsa.research_portal --study starbucks --margin 3 --contact-cost .15 --json
python -m dsa.research_portal --study starbucks --budget-mode fixed
python -m dsa.research_portal --ledger
```

它读取随 wheel 打包的 JSON，无需原始数据、数据库、模型 API、密钥或原研究目录。默认只使用开发阶段选定的主策略；没有根据测试结果重新挑选参照。输出中的金额是明确假设情景，默认每万名目标客户联系 1,000 人。

可选页面：

```bash
python -m streamlit run src/dsa/agent/workbench.py
```

页面另需 Streamlit 等完整产品依赖；公开仓库可安装 `.[full]`。侧栏选择“研究证据与业务决策”。该分支在进入数据库、模型模式读取和 Agent 图初始化前返回。它展示四个案例、冻结主策略、成本输入、配对差值、探索账本和源文件哈希，不生成客户名单或发起投放。

## 哪些事情已经衔接

|功能|实验分析工作区|研究工作区|
|---|---|---|
|数据来源|自建 PostgreSQL 的登记实验|随安装包发布的冻结聚合 JSON|
|结果计算|受限工具执行已登记统计|已有区间的单位与成本情景变换|
|自然语言提问|规则解析、澄清、限制、程序报告|无自由提问、训练或模型选择|
|最新 Starbucks|没有接入默认执行链|只读显示冻结评价和业务条件|
|归档|保留原运行和效果重算机制|显示证据路径/哈希；命令行 JSON 可另存新文件|
|可证明的能力|有限任务的可靠分析交付|研究阅读、决策边界与版本披露|

研究工作区自身不调用 LLM；展示没有真实模型模式横幅是因为没有发生模型调用。原实验工作区仍保留模式与能力提示。旧节点注释已同步为“结构化程序报告”，历史解释守卫只兼容旧记录。

## 证据与资源

`src/dsa/resources/research_catalog.json` 保存四个案例的摘要，以及 Starbucks 冻结策略和参照的汇总效果。`exploration_ledger.json` 保存分支、修订与来源哈希。代码位于 `src/dsa/research_portal.py`，页面在 `src/dsa/agent/research_panel.py`。

公开仓库 `reports/evidence/` 只放已核查且可公开的协议、冻结记录和聚合结果；内部阶段范围文件保留本地，账本明确标记不可公开、仅保留身份哈希；源文件名与 SHA-256 可和资源索引核对。原工作目录保留客户级预测、模型、原始数据和全部历史记录，公开仓库不包含这些文件。索引哈希证明公开文件与该次选取源文件的字节一致，不证明企业数据生成机制。

当前公开范围可以运行合成演示、研究情景与离线测试，也能核对展示汇总；**并不提供从私有完整运行目录一键重训最新实证的能力**。完整实证仍需遵循数据来源、原协议、数据版本、成员与冻结过程。不能以合成演示通过代替真实实证复现。

## 本轮验证范围

先补失败测试，再实现经济边界和研究路由，保存红/绿结果；测试无服务成本决策、读取包资源、强制配额和页面切换。安装验证在仓库外加载 wheel，确认不是源码注入。

新验证日志在原工作工程的独立维护目录保留，公开范围见[环境与验证](ENVIRONMENT.md)。历史 889 项产品验收、旧 API 批次与原研究结果保持原记录，本轮没有全量重跑数据库、重训或再次调用真实 API；不能把旧成绩累加成新成绩。远端结果以当前提交的 GitHub Actions 为准。
