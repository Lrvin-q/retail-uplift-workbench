# 真实结果与能支持的判断

发送促销邮件可能总体有效，但这不保证模型知道该发给谁。这个项目将“平均效果”与“同样资源下选人是否更好”分开检验，保留成功、未检出及无法识别的结果。

## Hillstrom：平均有效，未证实额外选人优势

64,000 名客户三组实验。男装主题邮件组 21,307 人中267次购买，无邮件组21,306人中122次购买；14天 ITT 购买率差为 **0.68050065 个百分点**，Newcombe 95%区间 **[0.50143447, 0.86407234]**。这是历史结果后指定的主比较。

既有测试集8,523人仅83次购买。扩展比较21个增量候选与1个普通购买基线、五档触达比例，共110项；31项点估计为正，0项名义正向区间，0项家族同时正向区间。**没有证实优于同预算随机选人**，不能把未显著写成证明无效。

诊断指向购买事件少、响应差异难估、基础预测与名单稳定性有限、预设场景检验力不足；这些是证据支持的具体解释，并未确定全部模型失败的共同原因。旧测试集已看过，扩展结果都是探索性的。

## Criteo：正评分对比，因果收益尚未识别

实际使用v2.1的13,979,592条发布记录，测试集6,990,115条、20,397个购买标签。开发集在7个候选与5档比例中选择：全体首选普通购买预测HGB31，六个专门增量候选首选S-HGB7。

主比例名义10%，购买模型实际选择9.9864%。其相对相同实际比例随机基准的AIPW评分差为 **0.0756673个百分点**，35项Bonferroni区间 **[0.0631986, 0.0881360]**；S-HGB7为 **0.0745222**，区间 **[0.0623208, 0.0867236]**。

35项评分区间均为正，但它们共享样本，不能视为35次独立复制。公开数据经过与结果有关的非均匀抽样及处理比例重平衡，完整设计/抽样概率未知；原实验随机化不能直接保证发布后人群可比。因此不能把评分差当成发布人群或原业务的已识别因果购买增量。尚未证实专门增量方法优于普通购买预测，更没有利润或真实投放验证。
