# 指标字典 v1.0

> 本文定义第一版所有指标的**唯一口径**，以及数据字段的含义与取值。
> 配套机器可读版本：`docs/metrics.yaml`（供 Agent 与工具按标识读取）。
> 口径依据见 [02-分析协议.md](02-分析协议.md)。本文描述计划中的定义，执行结果需单独验证。

---

## 1. 数据字段字典

数据集 `hillstrom@2008-03-20`，一行 = 一名客户，共 64,000 行。

### 1.1 实验前特征（可用于建模输入）

| 字段 | 类型 | 取值范围（实测） | 含义 | 备注 |
|---|---|---|---|---|
| `recency` | int | 1 ~ 12 | 距上次购买的月数 | 越小越近。**单位未在原始说明中明确**，按「月」理解，标注为待核实 |
| `history_segment` | 类别 | 7 档：`1) $0 - $100` … `7) $1,000 +` | 历史消费金额分箱 | 字符串内含序号，解析时注意 |
| `history` | float | 29.99 ~ 3,345.93 | 历史消费金额 | 与 `history_segment` 应一致，需交叉校验 |
| `mens` | 0/1 | 0, 1 | 是否购买过男装 | 实验前行为 |
| `womens` | 0/1 | 0, 1 | 是否购买过女装 | 实验前行为 |
| `zip_code` | 类别 | `Surburban`, `Urban`, `Rural` | 居住地类型 | 注意原始数据拼写为 `Surburban`（非 Suburban） |
| `newbie` | 0/1 | 0, 1 | 是否新客户 | 实验前状态 |
| `channel` | 类别 | `Web`, `Phone`, `Multichannel` | 历史购买渠道 | 实验前行为 |

### 1.2 实验分组字段

| 字段 | 类型 | 取值 | 含义 |
|---|---|---|---|
| `segment` | 类别 | `Mens E-Mail`, `Womens E-Mail`, `No E-Mail` | 随机分配的实验组 |

### 1.3 实验后结果字段（**禁止作为建模输入**）

| 字段 | 类型 | 取值 | 含义 |
|---|---|---|---|
| `visit` | 0/1 | 0, 1 | 实验后两周内是否访问网站 |
| `conversion` | 0/1 | 0, 1 | 实验后两周内是否购买 |
| `spend` | float | 0 ~ 499.00 | 实验后两周内消费金额；未购买者为 0 |

> ⚠️ **`visit` / `conversion` / `spend` 是干预后结果，任何情况下都不得进入模型特征。**
> 违反此规则即构成数据泄漏。

### 1.4 数据质量实测

| 检查项 | 结果 |
|---|---|
| 缺失值 | 12 个字段全为 0 缺失 |
| 完全重复行 | 6,562 行（**不得据此去重**，见数据来源核查记录 §4） |
| `visit` 分布 | 0: 54,606 / 1: 9,394 |
| `spend` 零值占比 | 75% 分位数为 0，即多数客户未消费 |

## 2. 指标定义

### 2.1 主要指标

#### `conversion_rate` — 购买率

| 项目 | 定义 |
|---|---|
| 中文名 | 购买率 |
| 英文标识 | `conversion_rate` |
| 分子 | 该组 `conversion = 1` 的**客户数** |
| 分母 | 该组**全部**被随机分配的客户数 |
| 单位 | 客户 |
| 口径版本 | `v1.0` |
| ⚠️ 约束 | **分母不得按 `visit` 过滤**（见分析协议 §8.1） |

### 2.2 次要指标

| 标识 | 中文名 | 分子 | 分母 | 备注 |
|---|---|---|---|---|
| `visit_rate` | 访问率 | `visit = 1` 的客户数 | 该组全部客户数 | 干预后结果，口径同理 |
| `spend_per_customer` | 人均消费 | 该组 `spend` 总和 | 该组全部客户数 | **分母含未购买客户**，否则高估 |
| `spend_per_buyer` | 购买者人均消费 | 该组 `spend` 总和 | 该组 `conversion = 1` 的客户数 | ⚠️ 条件于干预后结果，**仅描述，不作因果结论** |

### 2.3 效果量

| 标识 | 中文名 | 定义 | 用途 |
|---|---|---|---|
| `risk_difference` | 绝对差异（风险差） | $p_{treat} - p_{ctrl}$ | **主要效果量** |
| `risk_ratio` | 风险比 | $p_{treat} / p_{ctrl}$ | 辅助 |
| `relative_lift` | 相对提升 | $p_{treat} / p_{ctrl} - 1$ | 辅助 |

**边界规则**：对照组比例为 0 或极小时，**只报绝对差异**，并说明相对变化不可靠。

### 2.4 不确定性

| 标识 | 方法 | 适用 |
|---|---|---|
| `wilson_ci` | Wilson score interval | 单个比例（购买率、访问率） |
| `newcombe_ci` | Newcombe hybrid score interval | 两个比例的差异 |
| `katz_ci` | Katz 对数法 | 风险比 |
| `bootstrap_ci` | Bootstrap 百分位区间 | 消费类连续指标（需固定种子） |

> 不使用 Wald 区间作为主要方法：购买率属小比例（约 0.6%~1.3%），
> Wald 区间覆盖率不足且可能越界。

### 2.5 数据质量指标

| 标识 | 定义 | 用途 |
|---|---|---|
| `srm_p_value` | 卡方拟合优度检验 p 值（预期 1/3 : 1/3 : 1/3） | SRM 检查，α = 0.001 |
| `outcome_coverage` | 结果字段非缺失客户数 / 总客户数 | 覆盖率检查 |
| `join_row_ratio` | 关联后行数 / 关联前客户数 | 检测 JOIN 膨胀，应为 1.0 |
| `duplicate_customer_count` | 内部客户 ID 重复数 | 唯一性检查，应为 0 |

## 3. 比较配置

| 配置项 | 值 |
|---|---|
| 实验标识 | `hillstrom_email_v1` |
| 数据集 | `hillstrom@2008-03-20` |
| 主要比较 | `Mens E-Mail` vs `No E-Mail` |
| 次要比较 | `Womens E-Mail` vs `No E-Mail`（探索性） |
| 主要指标 | `conversion_rate` |
| 次要指标 | `visit_rate`, `spend_per_customer` |
| 结果窗口 | 实验后两周（固定） |
| 显著性水平 | 主要比较 α = 0.05 双侧；次要比较需 Bonferroni（α = 0.025） |
| 随机化单位 | 客户 |
| 分析单位 | 客户 |

## 4. 已定义但**不提供**的指标

以下指标**故意不定义**，因为数据不支持或会导致错误结论：

| 不提供的指标 | 原因 |
|---|---|
| 日/周维度的转化趋势 | 无日期字段与事件时间线 |
| 归因转化率（多触点） | 无触点链路数据 |
| 净收益 / ROI / ROAS | 无成本与毛利数据 |
| 个体增量（uplift）标签 | 每名客户只观测一个干预结果，原理上不可得 |
| 客户生命周期价值（LTV） | 只有两周窗口数据 |
| 复购率 / 留存率 | 窗口过短，且为单次快照 |
