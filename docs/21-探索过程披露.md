# 探索过程披露
更新：2026-10-16。本文是已保存记录的回顾性索引，不是事后补写的前瞻注册。

这个项目并非第一次尝试就取得正结果。它先研究邮件营销，再检查广告基准与其他公开数据，最后在一个公开随机促销练习中发现正向选人证据。读者需要同时看到这条探索路径，才能判断一项正结果的分量，而不是只看到最后成功的一页。

## 披露原则

当前没有跨数据集、跨研究的统一序贯检验或项目级错误率预算。因此，Starbucks 本轮固定策略的 95% 区间，不能解释为整个项目持续探索之后仍有总体 5% 假阳性保证。保留首次结果和局部多重比较控制有价值，但不能自动消除项目层面的选择。

机器可读账本在安装包的 `dsa.resources/exploration_ledger.json`；研究工作区和命令行可直接查看。它索引现存协议、结果、修订及 SHA-256，不能证明不存在未记录的思考或临时操作。本地时间与哈希支持内部一致性，不是外部不可篡改注册。

## 协议与范围变更不能省略

Hillstrom 扩展中购买预测参照是补充登记；女装记录继承部分参照元数据，不能用继承的时间冒称女装独立新注册。两条分支共用无邮件组，结果相关。

Criteo 保存两份修订：第一份增加普通购买预测参照；第二份增加发布样本处理比例的探索性敏感性。后者不修复未知发布筛选造成的识别缺口，也不替换原主要结果。历史缓存没有完整绑定全部输入/协议哈希，是复现债务，不能靠本次文档维护补成原本就完备。

原机制计划希望用交易时间验证补货周期与近期活跃。数据审查未提供合格资料。后续 Starbucks 范围补充只验证匿名特征选人，不再声称验证上述行为机制。它的训练/验证/测试与原计划默认比例不同，使用官方训练、测试及训练内验证；原因、实际成员与冻结证据保留在该轮协议及产物，不能抹平为“始终按最初方案”。

Starbucks 官方训练 84,534 人，其中拟合 63,400、验证 21,134；官方测试 41,650。先在开发资料选共享交互模型，再固定规则并冻结测试预测，随后开启标签评价。普通购买预测在测试上的点估计更高，但没有据此重新指定主要赢家，也没有继续调整复杂度、预算或种子。

## 统计证据的层次

1. 模拟检查方法在设定场景下的性质，不算真实数据正效果。
2. 同一研究内的冻结主检验和校正次要比较，各自说明角色。
3. 不同数据来源的结果不能直接合并。Criteo 发布评分不是购买因果效果，RetailHero 工程不是策略实验。
4. 整个探索过程未预先安排总体错误率；新队列或新政策实验才是下一步确认机会。

这项披露不否认已保存正结果的算术与本轮设计价值，也不把它升级成普适发现。当前目标是让读者知道“试过什么、为什么转向、哪里仍不确定”。

## 此后停止什么、继续什么

不再在已看过的留出结果上挑模型、预算或随机种子；不把重新划分旧数据称为全新独立验证；不通过改校正集合制造显著。

继续工作应取决于新条件：设计可核验且具有业务语义的数据，或者有真实毛利和可执行策略实验的新队列。若这些条件不具备，保留现有简单方案、失败与正结果，完善解释即可。本文与账本只追加维护，不覆盖首次产物。
