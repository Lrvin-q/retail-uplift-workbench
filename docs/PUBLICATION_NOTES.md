# 公开快照说明

本目录是从完整工作工程另行整理的公开作品快照。原项目、完整实验、失败记录和模型均保留在原工作目录，本次没有上传、创建远端仓库或推送提交。

## 纳入内容

产品Python源码及必需SQL/YAML资源；轻量合成演示；离线测试；关键统计/建模协议；两份最终研究报告、自有图表、聚合结果；独立研究估计器；安装、复现与许可说明。

## 未纳入内容

- `.env`及真实密钥、连接串、机器凭据；原`.git`和私有历史。
- 三套原始数据、客户级预测/划分/属性、训练模型、压缩数据与数据库文件。
- 真实API工具载荷、原始聊天、全量内部日志、调试缓存、临时文件、构建目录和虚拟环境。
- 第三方论文全文、字体、项目内复制的第三方Skills、旧报告/PPT压缩包。
- 带固定开发密码的本机Docker初始化与本机部署配置。

采用白名单复制，`.gitignore`用于后续开发防误提交，不能替代文件审计。`MANIFEST.sha256`列出本次快照内容；本次审计结论见[验证记录](ENVIRONMENT.md)。

公开报告保留原科学数字及局限。为GitHub阅读整理公式、图表锚点和文件说明；完整历史证据的表格描述保留并标明不全部包含于快照。聚合CSV不是原始数据，仅每个模型×比例一行。

## 后续准备发布

先把交付ZIP解压到原工程外的独立目录，再自行初始化新的Git仓库。不要把原工程的`.git`、`.env`、`data`、`artifacts`复制过去。本快照没有继承原仓库历史，也没有自动创建Git仓库。

提交前检查`git status`与`git ls-files`，再次运行测试和审计。若之后加入自己的数据或API配置，现有扫描不覆盖新增内容。许可证只覆盖作者有权许可的代码/文档，外部数据遵循来源条款。
