# 公开作品维护范围
更新：2026-10-16。

本仓库是从完整工作工程按白名单维护的公开作品。2026-10-15 初次发布包含 159 个文件；本次更新补充冻结研究、业务行动与只读研究入口。完整工作工程及私有 Git 历史均不迁入，首次结果保持原字节。

## 本次纳入

- 只读研究与成本情景代码、测试、安装包 JSON 资源。
- 业务行动、探索披露、产品/研究能力映射及最新 README。
- Starbucks 原实证 Markdown、自绘四图；协议、首次结果和冻结记录均为汇总/元数据。
- Hillstrom 男装/女装、Criteo 修订与数据资格的聚合索引与证据。

Starbucks 原报告保留历史结论；[业务行动补充](20-业务行动与证据边界.md)明确是否值得活动。报告中的匿名训练变量不是原始行数据。研究报告是作者写作，不复制第三方论文全文。

## 不纳入

密钥和真实连接串、原始数据、逐行客户属性与分数、真实名单、训练模型、数据库、真实 API 载荷、聊天、内部全量日志、虚拟环境、临时构建、第三方论文/字体/Skills、原私有 Git 历史。

即使匿名 ID 和行分数也不视为可自由公开。新增证据只包含每个模型/预算的汇总、协议和哈希。客户级冻结预测文件的哈希可公开，文件本身不公开。

## 验证与使用

`MANIFEST.sha256` 列出除自身以外的公开文件；发布前核对显式变更清单、路径、文件类型、秘密模式与本地已知秘密，不依靠 .gitignore 代替审计。没有把原项目整个目录或压缩包上传。

代码采用 MIT；第三方数据不随代码重新授权。来源与缺失条件见[数据来源](DATA_SOURCES.md)。新功能只读取冻结汇总；成本情景不是真实利润，离线演示不是生产业务。验证范围与限制见[环境记录](ENVIRONMENT.md)。

内部阶段范围计划明确标记 publication=false，因此保留本地、不上传其内容；公开账本只留文件身份哈希，数据资格结论另见聚合结果。使用 .gitattributes 禁止自动转换公开文件的换行，避免跨平台改变冻结证据字节与哈希。
