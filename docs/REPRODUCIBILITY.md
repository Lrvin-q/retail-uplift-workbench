# 复现范围

“能运行演示”“能核对历史汇总”“能从原始数据重新得到论文结果”是三种不同的验收。公开版分别说明范围，避免用一条安装命令暗示整套历史实证已全部复现。

|层次|公开材料|当前状态|
|---|---|---|
|无服务合成演示|代码、测试、生成器、默认样例|本次实跑；全新venv安装，不继承原conda依赖；不需原始数据。|
|统计与研究估计器|产品计算模块；独立AIPW、固定阈值、候选模块与离线测试|公开测试可执行，不读取私有数据库或模型。|
|历史汇总核对|两份最终报告、协议、聚合表与少量JSON|可检查展示数字和推断方向；文件哈希见MANIFEST.sha256。|
|完整产品业务|PostgreSQL SQL、数据导入、产品源码与安装说明|需要外部数据和本地服务；本次未重新冷启动整套服务。|
|Hillstrom/Criteo全量重训|原始数据、历史客户划分/分数、缓存与运行证据均不随公开版分发|不是本快照的一键入口；原工作目录保存完整记录。本次未重训，不用新的划分替代历史结果。|

`src/dsa/research`保留研究中使用的纯计算模块，导入改为包内相对导入；没有把依赖原机器布局的报告生成脚本或读取未绑定缓存的旧Criteo训练脚本伪装成通用命令。Criteo历史模型缓存未完整绑定输入/协议哈希，是明确的复现债务，后续重训须补充校验后另建运行。

模型比较在开发数据上选择，不能再根据已查看的测试结果反复换模型或触达比例。Hillstrom扩展探索使用已看过的旧测试，明确按探索性解释。统计量均以原保存结果为依据；本次公开整理不把旧验证结论升级为新确认性证据。

公共演示的SQLite仅用于解释交易粒度，不能替代PostgreSQL的真实负载、权限和查询计划测试。完整产品的模型登记、恢复、归档等功能需要额外服务，离线适配器不会假装它们已经执行。


## 2026-10-16 追加的复现层

`dsa.research_portal` 与可选研究页面只读取包内冻结聚合 JSON；可以在仓库外运行并复算成本情景。`reports/evidence/` 保存账本引用的协议、修订、首次结果和冻结元数据；公开测试逐个核对 SHA-256。哈希不代替随机设计核验。

Starbucks 原始数据、客户级划分/预测、模型与完整训练过程仍不随仓库分发。本次新增报告和证据支持核对汇总，不是全量实证重训入口。原报告位于 `reports/starbucks/report.md`；最新行动和探索限制另写补充，不覆盖历史原文。

没有重新测试标签、训练候选、改预算或搜索种子；整个项目也没有前瞻跨数据统一 alpha 保证。未来确认需要新队列或策略实验，不能把旧数据重新切分当作全新验证。
